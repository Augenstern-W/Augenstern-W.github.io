欢迎诸位来到 misc 的世界

MISC 是什么？

Misc（Miscellaneous），意为杂项。简单来说，不能被细分到其他方向的题都在 misc 里了（大乱炖）。就像它的名字一样，misc 包含了各种各样的题目，比如 Recon（信息搜集）、Encoding（编码）、Stego（隐写）、Forensics（取证）、Traffic（流量分析）、SandBox（沙箱逃逸）、Blockchain（区块链）以及今年最流行的 AI（学不完，根本学不完）。

说完分类，接下来讲讲考点。misc 平等地考察出题人和做题人——出题的思路够不够清奇，做题的思路够不够天马行空。misc 中可以有相当多的创新题（创死新人的题），还有一些常被提及但也相当有趣的知识点。在这里你可以看到平时互相发送的文件、照片、音频中加入了奇妙的 flag，当然，没说游戏不行😏。

misc 的题目大体围绕这几条主线展开：

  • 隐写：图片（webp、png、jpg、gif）、音频（mp3、mov 等）、视频（mp4 等）、其他
  • 压缩包处理：zip、rar、7z 等压缩包密码爆破、解压、拼接
  • 流量分析：计算机网络协议、文件传输、USB、WIFI
  • 数字取证：日志分析、内存取证分析、文件镜像取证、电子取证
  • 脑洞题：说不尽……，多是送分或者压分、彩蛋题

工具方面先混个脸熟：Kali 自带的 binwalk、foremost；十六进制编辑器 010 Editor 或 WinHex；WinRAR；以及 WPS。这些工具贯穿后面所有实战环节。

MISC 到底难不难？

作为杂项（乱炖），misc 对于新人是相当友好的，它能在短时间内激发你的兴趣并且学到各种知识。

但是创新题成功拉高了 misc 的难度——整不出正经题目的 misc 往往是最会整活的。你需要了解各方面的一点（确信）知识来保证能识别出题目考了什么（没说和游戏没关系嗷）。因为是杂项，了解其他方向的知识对解 misc 的题目也会有帮助（不能完全归类 ≠ 不是）。（misc 手人均全栈）

misc 也相当考验你对新知识的接受度。大多数时候你的 misc 旅程会是在做中学，学完立刻实践，纵享开箱即用的丝滑感。

如今大模型格外强力，misc 的多数题都能被一键解决（脑洞题依旧创人），所以显得简单。笔者在这里希望各位是来享受学习新知识并加以实践的乐趣，而不是为了成绩（其实成绩除了供面试参考外也没啥作用）用 AI 一把梭。

如何入门 MISC

这里沿用 24、25 入门指北的指导。

misc 相较于其他方向的入门还是很友好的，就算你之前是不怎么会用电脑的小白，入门 misc 也不会有太大的阻碍，还可以学会很多东西哦！

前期学习 misc 方向的内容，可以跟着本次比赛的题目，去见识一下 misc 各个小类别的常见考点，这些考点通过做题就可以很好地掌握。

有时候一道 misc 题可能会考到一个不常见的传输协议，又或者是图像处理等等陌生领域的知识，这时候就需要你去”现学现卖”，有的时候一个题可能一个队伍都解不出来（呜呜呜我又爆零了）。

在做题的过程中，你需要利用搜索引擎（Bing 或者 Google 等）。一定要会用搜索引擎寻找相关资料，你可能会找到和这次赛题解题思路类似的题目，跟着题解的思路复现，再加上一点点变通，很容易就能解出来。也有可能，这道题你啥思路都没有，这时候你可以再仔细看看题目描述或者附件，里面的每个字都有可能藏着解出这道题的关键提示！

当你觉得自己对 misc 方向已经有了不错的了解，就可以考虑深入学习取证、流量分析等等方面的内容，或许你能从中找到乐趣！

当然，在做题之前，我们需要有一定的计算机知识，这些知识可以提前学好再去做题，也可以在做题过程中边做边学（推荐后者）。

学会使用虚拟机！

虚拟机是一个强大的工具——创建一个虚拟机，就相当于你多了一台”独立的电脑”。你甚至可以创建不同操作系统的虚拟机，并且在两者之间自由地交换文件！有的时候，题目或者工具的运行环境和本机不一样，这时候虚拟机就派上用场了：你可以在一台电脑上，运行来自不同操作系统的程序。

  • 虚拟机软件用的是 VMware（学长的选择，新手也可参考 devops 入门指北选择 VirtualBox）
  • WSL（笔者在用）基本可以满足在 Windows 上面使用 Linux 操作系统的需要——想用 Linux 工具但不想系统学习的话是一个不错的抄近道选择，但抄近道是要付出代价的

具体的安装使用教程网上多如牛毛，这里就不详细展开了。

认识 Linux！

Linux 是一种开源的类 UNIX 操作系统内核，运行速度远超 Windows 系统，只要在终端里敲敲键盘就能完成几乎所有工作。（黑客在电脑上疯狂敲键盘黑入系统的样子离你似乎不是很远？）

尝试一下？可以试试安装 Ubuntu、Fedora、Debian 等等，然后熟悉一下 Linux 指令！总不能千辛万苦 getshell 之后，发现自己不懂 shell 指令，获取不了 flag 吧。

如果你已经足够熟悉了 Linux，那么可以试试 Kali Linux，里面有很多 CTFer 常用的工具，并且安装即用，省去了大部分配置环境的麻烦事。

遇到困难的时候，可以利用搜索引擎搜索报错的内容，网上会有很多人遇到相似的问题，并且他们很有可能已经有了解决方案！有时候，问问 AI 也可能有奇效哦（笔者建议不要尽信 AI，不然会死得很惨）。

学会一门编程语言！

misc 经常会出现需要编程对文件进行数据处理的情况，这时候学的编程语言就派上用场了。

对于从未接触过编程的同学，推荐先学 Python，因为它短小而通俗易懂（笔者推荐大一要学 C 的也学一下，因为开箱即用确实比学校教的基础方便很多，更多的编程语言请自行探索）。

学习编程语言，首先要了解各种逻辑的执行方式：分支、循环等等；然后了解对应的代码写法；再尝试着使用代码来实现一些简单的功能，甚至可以写写游戏。当你做得差不多时，恭喜你，这门编程语言已经可以为你所用了。

当然，Python 不止于此。在 misc 中，有一种专门针对 Python 语言的题目（pyjail），你需要通过执行有一系列限制条件的 Python 代码获取远程靶机的 shell 权限，这也是一类很有意思的题哦！（划线处内容详见 SandBox 入门指北）

MISC 题型

Recon（信息搜索）

“hyw，我就拍了个旅行纪念照，你就给我盒了？”

信息搜集题是通过照片或文字——现在还有电子账户等的信息——推断出一些有价值的东西。对于这种题，我们也有很多工具，比如国内的百度地图、国外的 Google 地图、百度识图等等，甚至是实 (xian) 地 (xia) 考 (zhen) 察 (shi)，都可以给你意想不到的收获。

比如前年的 moe 新生赛要找一个画刊上的内容，主播（E=hv）在网上找了半天最后惊奇地发现西电的图书馆里居然就有！今年也可以让各位体验到开盒的惊喜感。

E=hv 留言：信息搜集的尽头是线下真实。

Encoding（编码）

在这里，你能看见各种各样奇奇怪怪的编码：像 base 家族、社会主义价值观加密、snow 加密，或者是跟对照表一个个对照解码——比如福尔摩斯跳舞的小人（或许有人在解谜类游戏里见过？）、标准银河字母（mc 还在追杀我）。

这里推荐 CyberChef，属于是解码的神器了。古典编码现在也逐渐被归类到 misc，各位该实践你们的信息检索能力了，自行搜索了解一下吧，后面大概率要用的哦 OvO。

Stego（隐写）

隐写，通俗易懂：隐藏信息。至于怎么隐藏——你可以给他设个密码，或者是”什么叫图片里有个视频？””什么又叫图片里有个压缩包？””静图里不要塞动图谢谢”。

神奇的隐写能做到在各种文件里藏东西：图片、音频、视频、压缩包，甚至是文本。用十六进制文本查看器（010 Editor / WinHex）直接抄他老底，一个字节一个字节的找问题，关键位置往往有惊喜。

加密的怎么办呢，好难找啊 QAQ。图片隐写推荐 Stegsolve，有各种功能，更多隐写各位可以日后自行探索。

Forensics（取证）

这里借用学长的解释：”一个内存镜像，破解出了我妈给我电脑设的开机密码！”

取证就是对转储下来的内存或者磁盘的内容进行分析，从中提取信息。通过内存分析，我们可以获得很多有用的信息，比如刚刚输入了啥命令、桌面上有什么东西，甚至是开机密码，都可以知道。

常用工具：

  • 内存分析：Volatility
  • 磁盘取证：VeraCrypt（处理加密卷）、Elcomsoft Forensic Disk Decryptor 等
  • 还有 VMware（有时候会给你扔一整个虚拟机来分析。4G 的超大附件 vs 百度网盘）

Traffic（流量分析）

“为什么我偷偷发了点奇奇怪怪的东西就被警察蜀黍发现了 TAT”

流量分析就是通过捕获网络中的流量包，分析协议等等，可以获取传输的各种文件，或者是通信的设备名称。在 CTF 中，这类题目大多是给一个捕获的流量包（.pcap / .pcapng），然后从中分析数据，但难点在于如何定位到我们需要的那部分传输文件等等的流量。

当然，流量并不全是明文传输的，有的流量是经过加密的，这时候就需要一些其他的手段来解密流量。

流量分析常用的工具是 Wireshark，可以去网上搜搜如何使用哦！

文件分离

认识了文件类型，接下来讲文件分离。

为什么要分离？在 CTF 这个充满脑洞的比赛中，出题人往往会以稀奇古怪的方式出题（因此你可以常常看见”暴打出题人”的字眼出现在比赛论坛中）。一个文件中隐藏着另外的文件是经常出现的情况，这就需要掌握文件分离的技巧来应对。

Binwalk

Binwalk 是一个自动提取文件系统的工具，可以自动完成指定文件的扫描，智能发掘潜藏在文件中所有可疑的文件类型及文件系统。相比只能把文件识别成单一类型的 file 命令，Binwalk 能很好地看出文件里是否还藏着别的东西。

-e 全名就是 extract 的缩写。若提取成功则会生成一个名为 _extracted 的目录，里面存放的就是提取出的文件。

建议在 Linux 上安装 Binwalk，Windows 版不太推荐，比较鸡肋而且还会造成”环境污染”。

后续你从事网安行业时，或者打 CTF 尤其是杂项这个方向，工具、脚本、环境配置特别多，一道 MISC 题用十个工具解答也不惊讶。稍不注意，下载破解版、私人汉化的工具可能会挂马，导致计算机中毒！！再者很多工具和环境都要求 Linux 系统，所以建议还是安装一台 Kali 或者 Ubuntu 虚拟机更好。

隐写术

图片隐写术

遇到图片隐写，直接 binwalk + foremost 连招起手。连招没收获时，就要考虑更细的隐写手法了。

LSB 隐写

LSB 隐写，也就是最低有效位（Least Significant Bit）。图片中的像素一般由三原色组成，由这三种原色可以组成其他各种颜色。例如在 PNG 图片的储存中，每个颜色会有 8 bit，LSB 隐写就是修改了像素中最低的 1 bit，写入加密信息，而人眼无法注意到前后的变化。

例如某张图看起来只是六只环保色猪头，但其中包含了一张隐藏的二维码。我们用 Stegsolve.jar 打开此图，通过下方的按钮切换通道直到 Gray bits，可以看到左上角出现了隐写在该通道的二维码，扫描二维码即可得到 flag。

图片隐写神器 —— stegsolve

LSB 隐写、逐帧观察动图，都用到了这个工具。今天做 CTF 隐写术的题偶然发现这款隐写图片查看的神器 —— stegsolve，分享给大家。

下载地址：http://www.caesum.com/handbook/Stegsolve.jar

安装配置：需要先安装 Java 并配好环境变量（具体配置过程网上一搜一堆，这里不赘述），之后直接双击打开就可以使用😄。

软件界面简单，核心功能都在 Analyse 菜单下，作简单介绍：

  • File Format：文件格式，查看图片的具体信息；
  • Data Extract：数据抽取，对图片中隐藏数据进行抽取；
  • Frame Browser：帧浏览器，主要对 GIF 之类的动图进行分解，动图变成一张张图片便于查看；
  • Image Combiner：拼图，图片拼接。

音视频隐写术

音频相关的 CTF 题目主要使用的隐写策略分为 MP3 隐写、LSB 隐写、波形隐写、频谱隐写等。常用工具：

  • Audacity / ocenaudio：音频编辑工具软件；
  • Mp3Stego：将需要加密的数据压缩加密隐藏在 MP3 文件中；
  • Video to Picture：将视频的每帧提取转换成图片；
  • QR Research：CTF 中常用的二维码识别软件；
  • ImageMagick：免费的创建、编辑、合成图片的软件。

压缩包解密

压缩包有时候给到你时会设置密码不让你打开，有可能是伪加密，也可能是真加密。

通用排查方法：

  1. 用 WinHex / 010Editor 打开，搜索字符 pass、key、ctf、flag 等，查看是否藏有压缩包密码；
  2. 要爆破的话，先拿 0-6 位纯数字来一遍；
  3. 爆破不成功可以根据题意或社工猜密码组合，例如用户名叫王方，密码就有可能是 wangfang123；
  4. 检查是不是伪加密；
  5. 尝试明文攻击；
  6. 最后还有 CRC32 爆破兜底。

下面按顺序展开几个重点手法。

压缩包伪加密

zip 文件由 3 部分组成：压缩源文件数据区 + 压缩源文件目录区 + 压缩源文件目录结束标志。

在压缩源文件数据区和压缩源文件目录区各有一个 2 字节的全局方式位标记，用以标记是否加密，如下图（搬运）：

若是没有加密的 zip，两处标记都是 00 00：

加密的 zip 两处都不是 00 00（好像不同版本的压缩软件或算法，这里的值会不同，网上多见的是 09 00）：

若把未加密 zip 的压缩源文件目录区的全局方式位标记改为 01 00（或 09 00），就会被压缩软件认为是已加密——这就是所谓的伪加密：

破解伪加密的 zip 也简单：把标记改回 00 00 即可解压。

CRC32 碰撞

CRC 校验在数据存储和数据通讯领域为了保证数据的正确性而被广泛使用。CRC 的全称是循环冗余校验。

总之，每个文件都有唯一的 CRC32 值，即便数据中一个 bit 发生变化，也会导致 CRC32 值不同。若是知道一段数据的长度和 CRC32 值，便可穷举数据并与其 CRC32 对照，以此达到暴力猜解的目的——但通常只适用于较小的文本文件。

如何更快提升自己

笔者开始于：”这是什么？这怎么搞？” 学长的建议是，或许可以自己找一些题目自己练练手，或许就对 misc 方向的考点更加得心应手了。

可以去 BUUCTF 和 ctfshow（笔者有些工具从这找的）上找一些题目做做。可以先从简单的题目（一般解出人数最多）上手；如果完全没有思路的话可以看看题解（善用搜索引擎），因为做不出来有可能是题目涉及到了你之前没见过的考点，直接去看题解可以帮助你更快地掌握知识！当然，你也可以选择不看题解来锻炼自己的解题思维。总之，哪种方法适合你就去做！
